# ChainPulse - High Fidelity Crypto Portfolio Tracker

ChainPulse is a state-of-the-art crypto portfolio tracker with a "Neon & Technical" design aesthetic, built for traders who demand precision and speed.

## 🚀 Key Features
- **Unified Portfolio**: Consolidated view of assets across 20+ chains.
- **Real-time Engine**: Simulated HFT data feeds and live pricing Marquee.
- **Command Center**: Intuitive high-fidelity dashboard for multi-chain monitoring.
- **Lead Capture Integration**: Functional lead capture form integrated with n8n webhooks.

## 🛠️ Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Animations**: GSAP (ScrollTrigger), Framer Motion
- **Icons**: Lucide React
- **Styling**: Vanilla CSS with custom design tokens

## 📦 Getting Started

First, install the dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
